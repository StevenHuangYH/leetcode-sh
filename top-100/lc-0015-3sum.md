## 1. Problem Statement / 题目描述

* **[EN]** Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.
  * **Note:** The solution set must **not contain duplicate triplets**.
* **[CN]** 给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。
  * **注意：** 答案中**不可以包含重复的三元组**。

## 2. Updated Code Implementation / 更新后的完整代码

```python
from typing import List

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        # the order of triplet does not matter
        # i < j < k
        # the result cannot include repeated triplets

        result = []
        n = len(nums)

        for i in range(0, n - 2):
            x = nums[i]
            if i > 0 and x == nums[i - 1]:
                continue

            # Optimization 1: 最小和剪枝
            if x + nums[i + 1] + nums[i + 2] > 0:
                break

            # Optimization 2: 最大和剪枝
            if x + nums[-2] + nums[-1] < 0:
                continue

            j = i + 1
            k = n - 1
            while j < k:
                s = x + nums[j] + nums[k]
                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:
                    result.append([x, nums[j], nums[k]])
                    j += 1
                    while j < k and nums[j] == nums[j - 1]:
                        j += 1
                    k -= 1
                    while k > j and nums[k] == nums[k + 1]:
                        k -= 1
                        
        return result
```

## 3. Step-by-Step Code Walkthrough / 代码逐行详解

### 1. 数组排序与初始化 (Sorting & Initialization)

```python
nums.sort()
result = []
n = len(nums)
```

* **[EN] Action:** Sorts `nums` in ascending order. Initializes the empty list `result` and records array length `n`.
  * **Why Sort?** Sorting provides monotonicity so we can adjust sums using two pointers and effortlessly skip duplicate numbers.
* **[CN] 动作**：将数组按升序原地排序，初始化结果列表 `result`，并获取数组长度 `n`。
  * **为什么排序？** 排序赋予了数组单调性，不仅能使用双指针按需调节和的大小，还能使相同数字聚集在一起，极大地简化了去重逻辑。

---

### 2. 外层循环与基准数去重 (Outer Loop & Anchor Deduplication)

```python
for i in range(0, n - 2):
    x = nums[i]
    if i > 0 and x == nums[i - 1]:
        continue
```

* **[EN] Action:** Fixes the first number `x = nums[i]`. We only need to iterate up to index `n - 3` because at least two elements (`j` and `k`) are required after `i`.
  * **Deduplication Logic (`x == nums[i - 1]`):** If the current value `x` is equal to the previous value `nums[i - 1]`, all triplets starting with `x` were **already exhaustively found** in the previous iteration. We skip it (`continue`) to prevent duplicate triplets in the output.
* **[CN] 动作**：外层循环枚举第一个基准数 `x = nums[i]`，遍历到 `n - 3`（即 `range(0, n - 2)`）即可，因为后面必须至少保留两个数给 `j` 和 `k`。
  * **基准数去重逻辑 (`x == nums[i - 1]`)**：若当前数与前一个数相同，说明以该数值开头的所有三元组在上一轮循环中**已经全部被找齐了**，直接跳过（`continue`），避免生成重复三元组。

### 3. 双向极端剪枝优化 (Two-Way Extreme Pruning) ⭐

这两处剪枝是面试与竞赛中的高级优化技巧，能大幅减少不必要的双指针循环：

```python
# Optimization 1: 最小和剪枝
if x + nums[i + 1] + nums[i + 2] > 0:
    break
```

* **[EN] Why `break`?**
  * In a sorted array, `nums[i + 1]` and `nums[i + 2]` are the **smallest possible numbers** that can pair with `x`.
  * If the sum of `x` with the smallest available numbers is already `> 0`, then any other pair $(nums[j], nums[k])$ where $j > i+1$ or $k > i+2$ will produce an even strictly larger sum ($> 0$).
  * Furthermore, all future anchors $x' = nums[i+1]$ will be $\ge x$, so their sums will also strictly exceed $0$.
  * **Conclusion:** No further triplets sum to $0$ anywhere in the array. We can safely **terminate the entire loop immediately (`break`)**.
* **[CN] 为什么直接 `break`？**
  * 在升序数组中，`nums[i + 1]` 和 `nums[i + 2]` 是能与 `x` 搭配的**两个最小的数**。
  * 如果 `x` 加上后面最小的两个数之和都大于 0，那么搭配后面任何更大的数，和必然也都大于 0。
  * 不仅如此，后续所有的基准数 $x'$ 都会更大（$\ge x$），三数之和必定全部大于 0。
  * **结论**：后续不可能再存在任何和为 0 的三元组，直接 **彻底终止外层循环 (`break`)**。

---

```python
# Optimization 2: 最大和剪枝
if x + nums[-2] + nums[-1] < 0:
    continue
```

* **[EN] Why `continue`?**
  * `nums[-2]` and `nums[-1]` are the **largest possible numbers** in the entire array.
  * If `x` added to the two largest numbers is still `< 0`, then `x` is too small to reach $0$ with **any** pair in the remaining array.
  * However, a future anchor $x' = nums[i+1] > x$ might be large enough to achieve a sum of $0$.
  * **Conclusion:** We cannot use this specific `x`, but future anchors might work. We skip only this `x` and move to the next iteration (**`continue`**).
* **[CN] 为什么使用 `continue`？**
  * `nums[-2]` 和 `nums[-1]` 是整个数组中**两个最大的数**。
  * 如果 `x` 连加上全数组最大的两个数，和都依然小于 0，说明当前这个 `x` 实在太小了，跟后面的任何两数搭配都不可能达到 0。
  * 但后面的基准数 $x' = nums[i+1]$ 会更大，后续可能有机会达到 0。
  * **结论**：当前 `x` 无法凑成 0，但后续更大的 `x'` 仍有可能，所以**仅跳过当前这轮循环 (`continue`)**。

### 4. 双指针扫描与内层去重 (Two Pointers & Inner Deduplication)

```python
j = i + 1
k = n - 1
while j < k:
    s = x + nums[j] + nums[k]
    if s > 0:
        k -= 1
    elif s < 0:
        j += 1
    else:
        result.append([x, nums[j], nums[k]])
        j += 1
        while j < k and nums[j] == nums[j - 1]:
            j += 1
        k -= 1
        while k > j and nums[k] == nums[k + 1]:
            k -= 1
```

* **[EN] Logic:**
  * If $s > 0$: Sum is too large $\rightarrow$ decrease by moving right pointer left: `k -= 1`.
  * If $s < 0$: Sum is too small $\rightarrow$ increase by moving left pointer right: `j += 1`.
  * If $s == 0$: Found a valid triplet!
    1. Append `[x, nums[j], nums[k]]` to `result`.
    2. Move `j += 1`, then skip consecutive identical elements with `while j < k and nums[j] == nums[j - 1]: j += 1`.
    3. Move `k -= 1`, then skip consecutive identical elements with `while k > j and nums[k] == nums[k + 1]: k -= 1`.
* **[CN] 逻辑**：
  * 若 $s > 0$：和偏大 $\rightarrow$ 右指针左移以减小和：`k -= 1`。
  * 若 $s < 0$：和偏小 $\rightarrow$ 左指针右移以增大和：`j += 1`。
  * 若 $s == 0$：找到一组有效解！
    1. 将 `[x, nums[j], nums[k]]` 加入 `result`。
    2. 左指针先走一步 `j += 1`，随后利用 `while j < k and nums[j] == nums[j - 1]: j += 1` 跳过所有与前一个相同的元素。
    3. 右指针先走一步 `k -= 1`，随后利用 `while k > j and nums[k] == nums[k + 1]: k -= 1` 跳过所有与后一个相同的元素。

## 4. Key Takeaways & Comparison / 核心知识点对比

### Optimization 1 vs Optimization 2

| 剪枝策略 | 判断条件 | 语义分析 | 执行动作 |
| :--- | :--- | :--- | :---: |
| **最小和剪枝 (Optimization 1)** | `x + nums[i+1] + nums[i+2] > 0` | 即使搭配**最小的两数**和依然 $> 0$，后续必然全部 $> 0$ | **`break`** (全停) |
| **最大和剪枝 (Optimization 2)** | `x + nums[-2] + nums[-1] < 0` | 即使搭配**最大的两数**和依然 $< 0$，当前 `x` 太小无解，但后序更大的 $x'$ 仍有可能 | **`continue`** (跳过当前) |

## 5. Complexity Analysis / 复杂度分析

* **时间复杂度 (Time Complexity):** $\mathcal{O}(n^2)$
  * 排序时间为 $\mathcal{O}(n \log n)$。
  * 外层遍历 $n$ 个数，内层双指针扫描最多 $\mathcal{O}(n)$ 次。加上双向极端剪枝后，实际运行时间会显著低于常规 $\mathcal{O}(n^2)$ 解法。
* **空间复杂度 (Space Complexity):** $\mathcal{O}(1)$ 或 $\mathcal{O}(\log n)$
  * 不计用于保存返回答案的 `result` 列表，算法只使用了几个指针变量，额外辅助空间为 $\mathcal{O}(1)$。
  * Python 的 `sort()` (Timsort) 需要 $\mathcal{O}(\log n) \sim \mathcal{O}(n)$ 的栈空间。
