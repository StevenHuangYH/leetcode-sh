## 1. Problem Statement / 题目描述

* **[EN]** Given an integer array nums, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`. Notice that the solution set must not contain duplicate triplets.
* **[CN]** 给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 0 且不重复的三元组。

### Constraints / 约束条件
* $3 \le \text{nums.length} \le 3000$
* $-10^5 \le \text{nums}[i] \le 10^5$

## 4. Step-by-Step Code Walkthrough / 代码逐行详解

基于原 Python 文件 [`problems/top-100/lc-0015-3sum.py`](problems/top-100/lc-0015-3sum.py) 中的实现进行逐行深入解析：

```python
from typing import List

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort() # 1. 数组预排序 O(n log n)
        result = []
        n = len(nums)

        # 2. 枚举第一个元素 nums[i]，保留至少两个元素供 j 和 k 选择
        for i in range(0, n - 2):
            x = nums[i]
            # 去重 1: 跳过重复的第一个数
            if i > 0 and x == nums[i - 1]:
                continue

            # 极致优化 1 (Min-Bound 剪枝): 当前 i 下可能构成的最小三数之和
            if x + nums[i + 1] + nums[i + 2] > 0:
                break # 最小和已大于 0，后续更大的 i 只会更大，直接 break 终止

            # 极致优化 2 (Max-Bound 剪枝): 当前 i 下可能构成的最大三数之和
            if x + nums[-2] + nums[-1] < 0:
                continue # 最大和仍小于 0，当前 i 不可能有解，跳到下一个更大 i

            # 3. 对撞双指针寻找 nums[j] + nums[k] == -x
            j = i + 1
            k = n - 1
            while j < k:
                s = x + nums[j] + nums[k]
                if s > 0:
                    k -= 1 # 和偏大，右指针左移
                elif s < 0:
                    j += 1 # 和偏小，左指针右移
                else:
                    # 找到合法三元组
                    result.append([x, nums[j], nums[k]])
                    j += 1
                    # 去重 2: 跳过重复的第二个数
                    while j < k and nums[j] == nums[j - 1]:
                        j += 1
                    k -= 1
                    # 去重 3: 跳过重复的第三个数
                    while k > j and nums[k] == nums[k + 1]:
                        k -= 1
        return result
```

## 5. Interview Simulation: Alternative Paradigms & Follow-up Pivots / 面试官追问演练

### 追问 1: 如果不能修改原数组（不允许排序），如何求解？

* **面试官**：如果输入数组不允许修改且不能排序，如何做到 $\mathcal{O}(n^2)$ 求解并去重？
* **候选人解析**：
  * 使用外层循环固定 `nums[i]`，内层使用哈希集合 `seen` 寻找 `-nums[i] - nums[j]`。
  * 为了去重，需将找到的三元组通过元组哈希集合（如 `tuple(sorted([a, b, c]))`）进行过滤。由于额外维护哈希表和排序元组，常数开销和空间复杂度明显高于双指针法。
